# 2048-AIPlay-Vision
一个基于计算机视觉的 2048 游戏自动玩家，使用颜色识别技术而非 OCR 来识别游戏状态，并采用 Expectimax 算法进行智能决策。An automatic player for the 2048 game based on computer vision employs color recognition technology instead of OCR to identify game states, and utilizes the Expectimax algorithm for intelligent decision-making.
