# 2048 AI 自动玩家 - 智能训练系统

基于计算机视觉和机器学习的 2048 游戏自动化解决方案。支持纯模拟训练（冥想模式）和实时图像识别（实战模式），采用 Expectimax 搜索算法配合自适应策略优化。

## 前言
这个readme和这个python都是AI一手写的。感谢2025羊城杯CTF线上赛出了一个基于Rust的基于Tauri漏洞的逆向题目，让我在无聊之余还能游玩如此美妙的游戏。

因为我也不知道这个蠢货AI写的Readme是怎么样的，我也懒得看了。脚本运行后，空格点击左上和右下，然后给脚本自动跑就行了。

核心策略是：大数字保留不动，每个相近的数据尽量倚靠在一起。优先保持同样的数字在一起和尽可能合成数字。

## 🧠 核心技术

### 1. Expectimax 搜索算法

**原理**: 在随机事件（2 或 4 的出现）下寻找最优决策

```python
def search(matrix, depth, is_player_turn):
    if depth == 0:
        return evaluate_board(matrix)
    
    if is_player_turn:  # 玩家回合（确定性）
        best_score = -∞
        for move in [up, down, left, right]:
            new_matrix = simulate_move(matrix, move)
            score = search(new_matrix, depth, False)
            best_score = max(best_score, score)
        return best_score
    
    else:  # 随机回合（期望值）
        expected_score = 0
        for empty_cell in get_empty_cells(matrix):
            # 90% 概率出现 2
            matrix[cell] = 2
            expected_score += 0.9 * search(matrix, depth-1, True)
            
            # 10% 概率出现 4
            matrix[cell] = 4
            expected_score += 0.1 * search(matrix, depth-1, True)
            
            matrix[cell] = 0
        return expected_score / len(empty_cells)
```

**优化措施**:
- **缓存机制**: 避免重复计算相同棋盘状态
- **采样策略**: 空格多时采样重要位置，减少计算量
- **剪枝**: 提前终止明显劣势分支

### 2. 评估函数设计

**多目标优化**:

```python
# 1. 合并潜力（最高优先级）
merge_score = 0
for 相邻相同数字:
    if value >= 128:
        merge_score += value * 5  # 大数合并极重要
    elif value >= 32:
        merge_score += value * 4
    else:
        merge_score += value * 2

# 2. 空格数量（生存基础）
empty_score = empty_count² * 500000

# 3. 相似数字靠近（为未来合并准备）
similar_score = 0
for 相邻数字 (v1, v2):
    if v1 == v2 * 2 or v2 == v1 * 2:  # 2倍关系
        similar_score += min(v1, v2)

# 4. 位置权重（角落策略）
grid_score = Σ(value * weight[position])

# 权重矩阵（左下角策略）
weights = [
    [2^15, 2^14, 2^13, 2^12],
    [2^8,  2^9,  2^10, 2^11],
    [2^7,  2^6,  2^5,  2^4],
    [2^17, 2^16, 2^2,  2^0]
]

# 5. 角落奖励
if max_value in corner:
    corner_bonus = max_value * 1500
else:
    corner_bonus = -max_value * 800  # 惩罚

# 6. 单调性
monotonicity = count(递增序列) + count(递减序列)
```

### 常见问题

#### 1. 实战模式识别不准确

**问题**: 棋盘数字识别错误

**排查步骤**:

```python
# 1. 启用调试模式

# 4. 检查游戏窗口
# 确保完全可见，无遮挡，无透明度
```

#### 2. Try Again 按钮检测失败

**问题**: 游戏结束后无法自动重启

**解决方案**:

方案1: 调整相对位置（推荐）
```python
# 根据你的游戏窗口大小调整
TRY_AGAIN_RELATIVE_X = 250  # 可能需要调整
TRY_AGAIN_RELATIVE_Y = 360  # 可能需要调整
```

方案2: 重新截取按钮图片
```bash
# 1. 游戏结束时截取 Try Again 按钮
# 2. 只截按钮本身（不要包含背景）
# 3. 保存为 try_again.png
```

方案3: 禁用自动重启
```python
AUTO_RESTART = False  # 手动重启游戏
```

#### 3. 冥想模式崩溃

**问题**: ValueError: cannot convert float NaN to integer

**原因**: 评分计算出现 NaN 或无穷大

**已修复**: 最新版本已添加 `math.isfinite()` 检查

#### 4. 训练速度太慢

**问题**: 冥想模式速度 <5 局/秒

**优化建议**:
```python
# 1. 使用静默训练模式
display_choice = 1  # 不显示棋盘

# 2. 减少搜索深度
def get_search_depth(empty_count):
    return 2  # 固定浅深度

# 3. 关闭调试功能
DEBUG_MODE = False
SAVE_SCREENSHOTS = False
```

#### 5. 机器学习数据丢失

**问题**: game_history.json 文件损坏

**预防措施**:
```bash
# 定期备份
cp game_history.json game_history_backup.json

# 或使用脚本自动备份
python -c "import shutil; shutil.copy('game_history.json', 'backup_$(date +%Y%m%d).json')"
```

## 🔬 技术细节

### 颜色识别原理

**欧几里得距离计算**:
```python
def color_distance(c1, c2):
    return sqrt((c1[0]-c2[0])² + (c1[1]-c2[1])² + (c1[2]-c2[2])²)

# 示例
target_color = (238, 228, 218)  # 数字 2 的标准颜色
sample_color = (240, 230, 220)  # 采样到的颜色
distance = sqrt((238-240)² + (228-230)² + (218-220)²)
         = sqrt(4 + 4 + 4) = 3.46  # 距离很小，匹配成功
```

### 游戏模拟器实现

**压缩与合并逻辑**:
```python
def _compress_and_merge(row):
    # 示例: [2, 0, 2, 4]
    
    # 步骤1: 移除0
    new_row = [2, 2, 4]
    
    # 步骤2: 合并相同
    i = 0
    while i < len(new_row) - 1:
        if new_row[i] == new_row[i+1]:
            new_row[i] *= 2        # 2*2=4
            new_row.pop(i+1)       # [4, 4]
            score_gain += new_row[i]
        i += 1
    
    # 步骤3: 补0
    new_row.extend([0] * (4 - len(new_row)))  # [4, 4, 0, 0]
    
    return new_row, score_gain
```
