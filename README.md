# 2048 视觉识别 AI 游戏机器人

一个基于计算机视觉的 2048 游戏自动玩家，使用颜色识别技术而非 OCR 来识别游戏状态，并采用 Expectimax 算法进行智能决策。

## 前言
这个readme和这个python都是AI一手写的。感谢2025羊城杯CTF线上赛出了一个基于Rust的基于Tauri漏洞的逆向题目，让我在无聊之余还能游玩如此美妙的游戏。

因为我也不知道这个蠢货AI写的Readme是怎么样的，我也懒得看了。脚本运行后，空格点击左上和右下，然后给脚本自动跑就行了。

核心策略是：大数字保留不动，每个相近的数据尽量倚靠在一起。优先保持同样的数字在一起和尽可能合成数字。
我一共测试了四把，有着3/4的通过率（即达到2048）。

识别方面用了颜色识别，因为OCR太慢了。所以也是基于图像识别（或者说颜色识别）的办法来解决的。

## 🎯 项目特点

- **无 OCR 依赖**：使用精确的颜色匹配技术识别数字，避免 OCR 的复杂性和不稳定性
- **智能 AI 算法**：采用 Expectimax 搜索算法，结合左下角策略优化
- **高精度识别**：基于 2048 游戏标准颜色方案进行精确匹配
- **自适应策略**：根据游戏状态动态调整搜索深度和决策优先级
- **实时可视化**：提供清晰的游戏状态显示和移动决策信息
- **🆕 机器学习**：自动记录游戏数据，学习最佳策略参数

## 🚀 核心功能

### 视觉识别系统
- **颜色匹配**：使用 RGB 颜色距离算法精确识别 0-2048 的所有数字
- **网格采样**：采用固定网格采样策略，提高识别稳定性
- **区域检测**：支持手动设置游戏区域，适应不同分辨率和窗口大小

### AI 决策引擎
- **Expectimax 算法**：考虑随机性因素的最优决策算法
- **左下角策略**：强化左下角权重，保持大数字在角落
- **合并优先**：优先识别和利用相同数字的合并机会
- **相似数字靠近**：鼓励 2 倍关系的数字相邻（如 64 和 32）

### 性能优化
- **缓存机制**：使用 LRU 缓存避免重复计算
- **自适应深度**：根据空格数量动态调整搜索深度
- **采样策略**：空格多时使用采样，空格少时全检查

### 🆕 机器学习系统
- **自动记录**：每局游戏自动记录策略参数和结果
- **数据持久化**：保存到 `game_history.json` 文件
- **策略优化**：根据历史数据自动选择最佳策略
- **多策略测试**：支持批量测试不同策略组合
- **统计分析**：提供详细的历史统计和对比分析

## 🧠 算法详解

### 1. 视觉识别流程
```
截图 → 游戏区域提取 → 4x4网格分割 → 颜色采样 → RGB匹配 → 数字识别
```

### 2. AI 决策流程
```
棋盘状态 → Expectimax搜索 → 移动模拟 → 状态评估 → 最优移动选择
```

### 3. 评估函数组成
- **合并潜力**：识别相同数字的合并机会
- **空格得分**：保持足够的空格数量
- **位置权重**：强化左下角策略
- **相似靠近**：鼓励 2 倍关系数字相邻
- **单调性**：保持行列的单调性

## 🐛 常见问题

### Q: 识别不准确怎么办？
A: 启用 `DEBUG_MODE = True` 查看颜色识别过程，确保游戏区域选择正确

### Q: AI 决策太慢？
A: 减少 `get_search_depth()` 中的深度值，或关闭 `SAVE_SCREENSHOTS`

### Q: 游戏区域检测失败？
A: 确保 2048 游戏窗口完全可见，重新运行区域检测
